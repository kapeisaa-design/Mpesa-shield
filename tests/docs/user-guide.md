# M-PESA Shield - User Guide

## 1. Introduction

M-PESA Shield is an independent educational application
that helps users identify common warning signs in
suspicious digital messages.

The application is designed for cybersecurity awareness.

It is not an official Safaricom application.

---

# 2. Important Safety Warning

Never enter real:

- M-PESA PINs
- OTPs
- Passwords
- Account credentials
- Bank-card details
- Private financial information

Use fictional or already-redacted messages
for demonstrations.

---

# 3. Starting the Application

The application has two components:

1. Frontend
2. Backend

The backend must be running before the frontend
can perform message analysis.
