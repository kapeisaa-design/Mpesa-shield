# M-PESA Shield

M-PESA Shield is an independent educational project
designed to help users identify suspicious messages
and learn safer digital practices.

## Important Disclaimer

This is an independent educational project.

It is not an official Safaricom service.

Never enter real:

- M-PESA PINs
- OTPs
- Passwords
- Account credentials
- Private financial information
